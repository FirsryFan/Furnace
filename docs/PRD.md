# 产品需求文档（PRD）

> 产品工作名：知序 Furnace（历史名 —— v0.1 撰写期暂定名，2026-09-07 定稿更名为 **Furnace**，见顶部状态块）
> 版本：v0.1（需求基线）
> 更新日期：2026-08-19

---

## 1. 产品定位

**一句话**：一个给班级同学一起使用的、离线优先的 Windows 桌面生产力软件，把思维导图、任务编排、时间板块和 Anki 背诵填空放进同一个轻量工具里，让知识、任务和时间互相打通。

### 要解决的问题

现有工具的问题：

- 不轻量：XMind / Notion / Anki / Todoist 等各自安装、各自维护。
- 不互通：思维导图里的知识很难直接变成背诵卡片或任务。
- 不智能：任务排期和背诵复习都要自己手动安排。

### 不做的事（当前版本）

- 不做复杂插件系统。
- 不做公网云同步/账号登录。
- 不做多人在线实时协作。
- 不做 iOS / macOS / Linux（后续只考虑 Android）。

---

## 2. 目标用户与场景

- **主要用户**：班级同学（高中生/大学生学习小组）。
- **使用方式**：每人 Windows 电脑本地安装；通过“知识包”文件互相分享知识点库。
- **典型场景**：
  1. 同学 A 整理一张思维导图，把其中关键知识点做成知识包，导出 `.kpak` 文件发给同学 B。
  2. 同学 B 下载导入后，本地自动生成可背诵的填空题/选择题/大题。
  3. 同学 B 随手添加任务，软件根据依赖、优先级、预估时间和时间块自动建议“先做什么、大概什么时候做”。
  4. 所有个人进度、任务、复习记录都只存在自己电脑上，不会因为分享知识包而泄露。

## 3. 核心功能需求

### 3.1 思维导图

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| MM-1 | 创建/编辑多张思维导图 | P0 |
| MM-2 | 节点支持添加、删除、重命名、折叠/展开 | P0 |
| MM-3 | 节点支持备注、富文本、链接、图片（可后置） | P1 |
| MM-4 | 支持树形布局，后续可加思维导图布局 | P1 |
| MM-5 | 节点可以“转为标签”，之后标签可关联到卡片/任务/时间块 | P0 |
| MM-6 | 节点可以关联到已有任务、卡片、时间块 | P1 |
| MM-7 | 支持撤销/重做 | P1 |
| MM-8 | 思维导图可包含在知识包中分享（不含个人数据） | P1 |

### 3.2 标签体系

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| TAG-1 | 标签可独立创建，也可由思维导图节点生成 | P0 |
| TAG-2 | 标签可赋予卡片、任务、时间块、知识点等对象 | P0 |
| TAG-3 | 标签有名称、颜色、说明 | P1 |
| TAG-4 | 支持按标签筛选/搜索 | P1 |

### 3.3 任务编排

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| TASK-1 | 任务支持标题、详情、状态（待办/进行中/完成） | P0 |
| TASK-2 | 任务支持子任务（树形） | P0 |
| TASK-3 | 任务支持依赖关系（前置任务） | P0 |
| TASK-4 | 任务支持优先级（高/中/低） | P0 |
| TASK-5 | 任务支持预估时间、截止时间、提醒 | P0 |
| TASK-6 | 任务可关联标签/思维导图节点/知识点 | P0 |
| TASK-7 | 自动分析：新任务随手添加后，给出“建议顺序”和“建议时间段” | P0 |
| TASK-8 | 自动分析规则可被用户查看/理解（不是黑盒） | P1 |

### 3.4 时间板块

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| TIME-1 | 时间是独立板块，可添加“时间块”（如：晚自习第一节、周末上午） | P0 |
| TIME-2 | 时间块有开始/结束、可重复、可用/忙碌状态 | P0 |
| TIME-3 | 时间块有标签/属性（如：高精力、低精力、适合背诵） | P1 |
| TIME-4 | 任务编排参考时间块，生成“建议时间段” | P0 |
| TIME-5 | 时间块本身可关联任务/标签 | P1 |

### 3.5 Anki 背诵与填空

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| ANKI-1 | 知识点库：每条知识点包含正文/答案/来源等 | P0 |
| ANKI-2 | 每条知识点可配置多个“挖空方式”模板 | P0 |
| ANKI-3 | 背诵填空时自动从多个挖空方式中选择一种呈现 | P0 |
| ANKI-4 | 三种卡片题型：选择题、填空题、大题 | P0 |
| ANKI-5 | 选择题：给出选项，选择后显示答案 | P0 |
| ANKI-6 | 填空题：输入答案后提交，显示答案 | P0 |
| ANKI-7 | 大题：不提供输入框，点击后显示答案，用于自测构思 | P0 |
| ANKI-8 | 间隔重复（spaced repetition）算法：SM-2 起步，预留 FSRS 升级 | P0 |
| ANKI-9 | 每日复习队列、复习统计（简单） | P1 |
| ANKI-10 | 支持从思维导图节点/标签快速生成知识点 | P1 |

### 3.6 知识包分享

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| PKG-1 | 导出知识包 `.kpak`（zip 格式），包含知识点、挖空模板、标签、可选思维导图 | P0 |
| PKG-2 | 知识包包含作者标识、包名、版本号、导出时间 | P0 |
| PKG-3 | 导入知识包时显示作者/版本，支持覆盖/升级/保留本地进度 | P0 |
| PKG-4 | 知识包**不包含**个人任务、个人时间、复习进度等隐私数据 | P0 |
| PKG-5 | 可选：知识包加密码保护（后续版本） | P2 |

## 5. 用户故事示例

1. **作为学生**，我想把老师讲的知识点做成思维导图，并把关键节点转成标签，方便以后给卡片和任务打标签。
2. **作为学生**，我想从同学分享的知识包里导入知识点，打开“背诵填空”就能自动出题，不用手动制作卡片。
3. **作为学生**，我随手添加“复习物理第3章”“写数学错题”，软件会告诉我先做哪个、建议放在哪个时间块。
4. **作为学生**，我复习完一组卡片后，软件按间隔重复安排下一次复习。
5. **作为学生**，我导出的知识包只包含学习内容，不含我的任务和复习记录，分享时不怕别人看到我在干什么。

---

## 6. 成功标准（MVP）

- 在 Windows 上能完成：
  - 创建思维导图，节点转标签；
  - 添加任务/子任务/依赖/优先级/时间块；
  - 导入知识包，自动生成三种题型并完成一次复习；
  - 导出知识包给同学导入；
  - 中英文切换。
- 全程无需联网、无需账号。

## 7. 待确认问题

以下问题暂不阻塞架构设计，但进入 UI/算法阶段前需要确认：

1. 思维导图是否需要自由画布/拖拽定位，还是树形缩进就够？
2. 任务“建议顺序”的算法期望：按截止时间？按依赖？按预估时长？按精力属性？还是组合？
3. 知识包是否需要支持图片/音频等附件（影响包体积）？
4. 复习统计需要多详细（连续天数、遗忘曲线、正确率）？
5. 产品最终名称和视觉风格？
