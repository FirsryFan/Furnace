# Furnace 使用指南

> 这份文档回答两件事：**Furnace 能替你做什么**，以及**怎么用才省时间**。
> 不是功能清单（那在 FEATURE_MATRIX.md），而是「今天打开它，先点什么」。
> 版本基线：v0.6.12（2026-10-28）。卡组主界面、AI 收题、运行时间线都已在安装包里。界面文案可能微调，入口位置不会大变。

---

## 1. 先看这里：三个最常用的入口

| 你现在想干什么 | 去哪里 |
| --- | --- |
| 把题目搞进库里（照片 / 粘贴 / 题库包） | 直接发给「智能」；整卷取题在题库页 |
| 复习、自测、看错题 | 知识（闪存卡 + 题库 + 错题本） |
| 安排时间、看今天该做什么 | Time（安排） |
| 让 AI 帮你查库、改库、出题、排卷、出 Word | 智能（底部「智能」，即 AI 对话） |
| 备份、恢复、导入导出、评测与认知档案 | 设置 |

**一句话用法**：日常在「收题 → 知识 → Time」三个页里点；要做批量/跨模块的事，直接去「智能」说人话。

## 2. 「智能」（AI）能做什么、不能做什么

AI 不是聊天窗口摆设，它**能读你的库、也能改你的库**（改之前会告诉你、能撤销）。

### 能做（按价值排序）

1. **查**：这周有什么任务、某标签下有多少题、哪些知识点没复习、某道题在哪。
2. **改**：建任务、改时间块、打标签、建知识点卡、改卡组的每日复习量——都是真写库。
3. **学**：今天先练什么、这科哪里弱、给我一份复习安排（会给理由，不是随机推荐）。
4. **题**：找相似题、按能力找题、按题号读题、读整份组卷网试卷、组卷。
5. **产**：把题目/资料生成 Word 文档（走排版流程，不是纯文本导出）。
6. **收题**：把题目拍照或粘贴给 AI，它誊写进题库（create_questions，一次最多 100 道）；重复题会指向已有题，撤销只删这次新建的。
7. **闪存卡**：考前专项——把某标签树下未来到期的卡提前到今天（见 §5）。

### 不能做（别指望，问它也会说做不到）

- 不会自己上网乱爬：给网址它才读（fetch_page）；组卷网走本地扩展桥，需要你浏览器已登录。
- 不会猜文件/题目名：库里没有就是没有，它会先查再说。
- 不会静默删除：删除类操作逐条确认，且留台账。
- 不联网也能用：AI 调用需要你配置的模型服务；不配模型时其余功能全部本地可用。

### 每一步都看得见（运行时间线）

以前只有「停止生成」，你不知道它卡在哪。现在一轮里每走一步都有一行状态：

- **模型轮**：第 N 轮 · 思考中 → 生成回答中，右侧实时秒表。
- **工具轮**：调用工具：read_question、参数摘要（题号/标签/路径）、执行完给结果摘要与耗时。
- **等你/失败/取消**：等待确认显示沙漏；失败与取消各有图标和原因，不会静默消失。
- **折叠**：本轮结束后整块自动折成一行「本轮 N 步」，点一下可以重新展开看全过程——追查「它为什么这么答」用这个。

时间线只是把已有步骤显示出来，**不改变工具执行顺序**，也不影响下面三条规则。

### 三条使用规则

- **先查再改**：「这个标签下有哪些题」永远比「把第 5 题删了」安全。
- **写操作可撤销**：会写库的回复下面有撤销入口，撤销恢复到操作前快照。
- **一次说一件事**：长指令拆成两步，成功率明显更高。

## 4. 一条完整闭环（建议按这个顺序用）

### 第 1 步：收（直接发给「智能」）

- 打开「智能」，把题目**拍照或粘贴**发过去，说一句「誊写进题库」。它会把题干、选项、答案、解析结构化后写入，并逐题告诉你哪几道新建、哪几道题库里已有。
- 一次多张图可以一起发：同一段对话里连着发多张，它会按顺序整理；**微信聊天记录里的图片**也能直接拖进对话框。
- 为什么不用先去「收题页」：手动入口已从题库页撤掉（题目详情页「找相似题」空态的「去收题」按钮也删了），收题统一走 AI（`create_questions` 工具，一次最多 100 道，可撤销）。
- 导入题库包（.tqb）：设置 → 题库包导入；**同一批再导入会按组卷网题号更新已有题目**，不会重复建。
- 整卷取题仍在题库页：组卷网整卷页 → 粘贴，走的是同一批入库逻辑。

### 第 2 步：整（题目详情）

- 补答案、解析、知识点、标签；**标签决定它以后进哪个卡组、哪个筛选**。
- 公式用 LaTeX（markdown 里写 $...$）；图片用 ［图N］ 占位，别把长题干挤在一行。
- 题干是整卡大图（截图）时，详情页/Word/组卷会自动换成「图 + 文字」显示，不用手改。

### 第 3 步：测（自测 + 作答记录）

- 题目详情页可直接自测、判分；错的对的都会记作答。
- 题库支持按「错 N 次」筛，错题本专门收这些。
- 自测整页防剧透：答案默认不显示，答完才给。

### 第 4 步：卡（闪存卡 / 复习）

- **主界面是卡组列表**（闪存卡页第一个 Tab「卡组」）：每行是一个卡组，直接显示今天的新卡/复习完成数与进度条，完成后打勾；还有「全部」和「未分组」两行兜底。点一行进入该卡组的背诵界面，回来进度自动刷新。
- 标签 = 卡组。给卡片挂标签，等于把它归进某个复习范围。
- 每个卡组可设「每天新卡上限 / 每天复习上限」——**这是控制工作量的主开关**，别一次拉太多。
- 复习节奏：新卡每 5 张复习插 1 张、重复出现有上限、可跳过/结束，避免反反复复那几张。
- 设置里可调「目标记忆保持率」三挡（更短/标准/更长），影响下次间隔。

### 第 5 步：时（Time）

- 时间块 = 你的安排。行高可以拖（8 档吸附），缩放用设置里的页面缩放。
- 「安排」顶部可在**全部 / 今天**之间切；「今日安排」标签树只放时间用途的标签。
- 标签有**用途边界**（时间/题目/知识/任务/闪存卡）：选错域的标签不会出现在选择器里，别硬塞。

### 第 6 步：评（评测与认知档案）

- 设置 → **评测与认知档案**：进的是评测中心，列着可做的能力任务（快速分类、Go/No-Go、倒序数字广度、2-back、Stroop、任务切换、疲劳块），点一行开始，全屏做，随时可退。
- 每个任务测完自动算**本次指标**（反应时中位数、d′、稳定跨度、切换成本……），再合并进你的能力档案（10 项能力）和认知参数（9 个，供安排/推送参考）。
- 档案里每项都带**来源与不确定性**：`默认`（还没测）/ `评测`（自动合并）/ `派生`（参数由能力推导）/ `覆盖`（你手填）。测得多，不确定性下降；不懂的数不用管，先信默认。
- 能力值是**个体内 z-score**（0 = 你自己的典型水平），不是智商、不是人群排名；测能力不测知识点，知识点自评在另一处。
- 想手改某一项：档案页点该项 → 覆盖；想恢复自动：点「清除覆盖」（数值保留，下次评测继续合并）。

## 5. 考前冲刺：让 AI 把复习提前（focus_review）

**场景**：下周三考试，某个板块的卡本来一周后才到期，你不想等到考完才复习。

**做法**：对「智能」说：

> 下周三考物理。把「物理/电磁学」下面未来 7 天到期的卡提前到今天，先预览给我看。

它会先跑**预览**（默认 dry_run），列出来会拉动哪些卡、各多少张：

- **会被拉**：未来 N 天内到期（默认 7 天）、不是新卡、还没到期。
- **不会被拉**：已经到期或已过期的（本来就该复习）、新卡（该按新卡节奏进）、超出 horizon 的太远卡、超过本次上限的卡。
- 排序按**原来到期时间近→远**，你要是说「最多 20 张」，它会拉最近的 20 张，其余告诉你有多少张没动。

**确认后再写**：看到预览觉得合适，再回一句「就这样，执行」。它会把这些卡的到期时间改成今天，并给你一个**撤销**入口（撤销逐张还原原到期时间）。

**边界（重要）**：

- 只改「到期时间」，**不改**每张卡的复习进度/熟练度（repetitions 等不动）。
- 卡组若设了每天复习上限，它会提醒你上限多少、超了会怎样，但仍按你确认的数量写——**你自己决定要不要分批**（建议按天分批：今天一批、明天一批）。
- 新卡不拉：新卡有自己的学习节奏，硬提前只会把「新卡额度」挤爆。
- 一次只处理一个标签子树；跨学科要分几次说。

## 6. 任务安排、题目推送：同一机制的现状

你提的需求是「手动调节推送」——不只闪存卡，任务安排和题目推送也该能提前/压后。

**已完成**：

- 闪存卡：focus_review（§5），按标签子树 + 天数窗口批量提前，预览、可撤销。
- 时间/任务：AI 能直接建任务、改时间块、排到某天某时段（manage_task / manage_time_block）；「安排」页支持全部/今天切换。
- 题目：AI 能按标签/能力找题、组卷、出 Word（recommend_practice / compose_paper / create_document）；题库支持批量打标签、筛选、排序。

**还没做（明确说清楚，不糊弄）**：

- 任务和题目的「批量提前/批量压后」**没有内置一键工具**。现在只能：① 让 AI 逐个改；② 题目走「组卷 → 生成 Word/试卷」当作专项练习，而不是改推送日期。
- 「题目推送」本身还没有独立的日程化队列（闪存卡有 FSRS 到期队列，题目还没有）。

**下一步优先级**（你拍板我再做）：任务侧做 plan_shift（按标签/时间段批量平移，同 focus_review 的预览+撤销模式）比题目侧更划算，因为时间块本来就有明确日期。

## 7. 让 AI 更懂你：用户自我描述（persona）

设置里可写一段「我是谁、怎么学、别怎么对我说话」。它会进 AI 系统提示，影响措辞和建议风格；**不影响**解题/整理/组卷的事实判断。写空 = 不注入，行为逐字节不变。

---

## 8. 数据安全

- 所有数据本地 SQLite + 本地文件；导入题库包前会自动备份当前库。
- 备份保留最近 10 份，可在设置里一键恢复。
- 题库包（.tqb）可导出选中/全部；再导入时按题号更新，不会重复。
- 学习数据可分区清空（设置 → 学习数据），清空前有确认。

## 9. 常见问题

**Q：公式显示成了源码？**
A：用 markdown + LaTeX 混排，公式写在 $...$ 里；AI 回复和题目正文都支持。整卡截图会按「图 + 文字」显示。

**Q：闪存卡老是那几张？**
A：① 卡组每天新卡/复习上限太大；② 目标记忆保持率调得太高。先把上限降下来，再看复习节奏设置。

**Q：知识网络图卡/太乱？**
A：图按标签分簇，支持缩放平移、搜索、标签筛选；点节点看详情。标签太碎时先合并标签，图会明显清爽。

**Q：页面字太小/太大？**
A：设置 → 页面缩放（80%–150%），整体缩放，不是只放大文字。

**Q：C 盘越来越满？**
A：构建产物和临时文件在 E:/dsh-tmp-aot 与 app/build；数据在应用数据目录。清缓存优先清 build 与旧 dist，不要删 data。

**Q：AI 说找不到题？**
A：先让它「查」——标签名要跟你库里一模一样；不确定就让它先列标签树。
