# 隐私与安全设计

> 工作名：Threadflow（定稿；历史工作名：知序 KnowFlow）
> 目标：个人数据默认不出设备。`.kpak` 班级分享只含用户主动选择的知识内容；`.tfpkg` 是用户主动的全量导出（含个人数据，默认加密可选）。
> 对齐依据：定稿 [THREADFLOW_SPEC.md](THREADFLOW_SPEC.md) §3（打包传输）、D4 双轨打包（[GAP_ANALYSIS.md](GAP_ANALYSIS.md)）；`.tfpkg` 格式细则见 [KNOWLEDGE_PACKAGE.md](KNOWLEDGE_PACKAGE.md) 第 7 节。

---

## 1. 隐私原则

1. **本地优先**：所有个人数据（任务、时间块、复习进度、设置）默认只存在本机。
2. **分享最小化**：`.kpak` 分享仍保持最小化——只包含用户主动勾选的知识内容，绝不包含个人进度/任务/时间数据；`.tfpkg` 是用户**主动**的全量导出（含个人数据），只在用户显式选择「导出工作区」时产生，加密默认可选（见 §4）。
3. **可解释**：导出前明确列出清单——`.kpak` 列“包含什么 / 不包含什么”；`.tfpkg` 明示“全量、含全部个人数据”（见 §3），用户确认后才生成文件。
4. **无遥测**：应用默认不联网、不上传任何使用数据。
5. **可选加密**：后续支持本地数据库加密和应用锁，防止本机被他人打开时泄露。

---

## 2. 数据存放位置

| 数据类型 | 存放位置 | 说明 |
| --- | --- | --- |
| 个人数据库（SQLite） | 系统应用数据目录 | 如 `%APPDATA%/threadflow/threadflow.db` |
| `.kpak` 分享包导出文件 | 用户选择的位置 | 只含主动勾选的知识内容（子集） |
| `.tfpkg` 工作区导出文件 | 用户选择的位置 | 全量（含全部个人数据）；用于自己的备份/迁移/整体传输，加密默认可选 |
| 附件/图片 | 应用数据目录下内部目录 | 随 `.kpak`（可选）与 `.tfpkg`（全量）打包 |
| 日志 | 应用数据目录下的 `logs/` | 仅本地，不自动上传 |

> 使用系统应用数据目录，而不是放在班级共享文件夹，避免其他同学直接看到你的个人数据。`.tfpkg` 含全部个人数据，尤其不要放入共享位置。

## 3. 导出隐私清单（`.kpak` 分享子集 / `.tfpkg` 全量导出）

### 3.1 `.kpak`（班级分享子集）

导出前，界面显示类似以下清单：

```
将包含：
  ✅ 12 个知识点
  ✅ 30 张卡片模板（选择/填空/大题）
  ✅ 8 个标签
  ✅ 1 张思维导图

不会包含：
  ❌ 你的任务和提醒
  ❌ 你的时间安排
  ❌ 你的复习进度和统计
  ❌ 你的本地设置
```

用户确认后才生成 `.kpak`（白名单导出器硬编码排除个人数据，见 §5 首行）。

### 3.2 `.tfpkg`（工作区全量导出，由「导出工作区」产生）

`.tfpkg` 是**全量**格式，无“不会包含”清单可言——导出前界面显示以下全量清单（同时固定展示 §7 的告知文案）：

```
将包含（全量，无筛选）：
  ✅ 你的全部任务（含子任务/依赖/提醒）与完成记录
  ✅ 你的全部日程时间块（含重复规则）
  ✅ 你的复习进度（卡片状态/复习日志/挖空历史）与 Thread 状态（精力/当前目标）
  ✅ 你的本地设置与个人档案
  ✅ 你的全部知识内容（知识点/卡片模板/标签/思维导图）与附件
  ✅ 你的主题配置（含背景图）
```

⚠ **文件含全部个人数据**：`.tfpkg` 用于你自己的备份/迁移/整体传输（导入可选「覆盖/追加」），**不是分享格式**。分享/外传前请三思：确有必要时在导出时设置密码（可选，见 §4），并只发送给你信任的设备/账号。

## 4. 可选本地安全措施

> 状态：`.tfpkg` 导出加密随打包能力（R4）落地，不再是“后续版本”；其余条目仍为后续能力。

- **应用锁**：启动时输入 PIN/密码才能打开（后续版本）。
- **数据库加密**：使用 SQLCipher 或类似方案对本地数据库加密（后续版本）。
- ~~**知识包加密**：导出时可选密码，导入时需要密码。~~ → **已勾销：`.kpak` 班级分享子集不做加密**（见 KNOWLEDGE_PACKAGE.md 第 7 节）。
- **`.tfpkg` 导出支持可选密码加密**：导出工作区时可设密码；AES-GCM 加密 manifest 与附件内容（依赖不可用时按 GAP O1：先留接口与本文档）；导入需先输入密码，密码错误即中止且不落数据；密码不保存、忘记无法找回。格式细则见 KNOWLEDGE_PACKAGE.md 第 7 节。
- **导出水印**：知识包可带作者标识，防止内容被恶意转发后无法溯源（后续版本）。

## 5. 威胁模型（简单说明）

| 威胁 | 当前对策 |
| --- | --- |
| 同学通过 `.kpak` 分享包看到我的任务/进度 | `.kpak` 格式白名单，导出器硬编码排除个人数据 |
| `.tfpkg` 文件被他人获取（丢失/误传/拷走） | `.tfpkg` 含全部个人数据：对策＝**可选密码加密**（AES-GCM，见 §4）＋**覆盖导入前自动备份**当前库（见 KNOWLEDGE_PACKAGE.md 第 7 节）；导出/导入页持续提示“非分享格式” |
| 同学直接翻我电脑文件夹 | 数据放在系统应用数据目录；后续可加应用锁/数据库加密 |
| 软件自动上传数据 | 默认无网络权限；只有用户主动导出/导入时才读写本地文件 |
| 知识包被篡改 | 后续可加哈希/签名校验（加密的 `.tfpkg` 另由 AES-GCM tag 提供完整性校验） |
| 电脑丢失 | 「导出工作区」生成 `.tfpkg`（可设密码）定期归档到自己的其他设备；恢复＝导入并选择「覆盖」（导入前自动备份现库） |

---

## 6. 权限说明

- Windows 版不需要网络权限。
- 本地通知需要系统通知权限（用于任务提醒）。
- 文件读写仅限用户主动选择导入/导出的路径。

---

## 7. 用户告知

- 首次启动显示“隐私说明”：
  - 个人数据只保存在本机；
  - 班级分享只走 `.kpak`，`.kpak` 不会包含个人任务/时间/复习进度/设置；
  - 本应用默认不联网。
- 「导出工作区」（`.tfpkg`）与导入页固定展示全量告知（文案建议）：
  - “`.tfpkg` 是**全量导出**：包含你的全部个人数据（任务、日程、复习进度、设置、个人档案、主题、附件）。
  - 它用于你自己的备份/迁移/整体传输，**不是分享格式**——请勿发给他人；确有传输需要请先设置密码，并只发给你的信任设备。”
