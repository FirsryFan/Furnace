## 1. 思维导图交互深度

- [ ] 只需要“树形缩进/折叠”就够，还是需要自由画布、拖拽定位、连线？
  - ✅ 定稿决定：Mindnet 是“成熟的、可编辑的思维导图工具”，支持节点增删改、**拖拽移动**、建立父子/兄弟连接关系（定稿 1.4.1；GAP §2.4 表）；现状树形编辑能力保留，拖拽跨父级 re-parent 列入 R6 打磨（GAP §2.4）。
- [ ] 是否要支持图片、公式、富文本？
  - ✅ 定稿决定：定稿未把导图节点内的图片/公式列为需求（1.4 功能集仅 1.4.1–1.4.3 编辑 / 导入导出 / 标签接口）；现有节点备注等基础能力保留（GAP §2.4 🟢 行）。富文本集中在 Knowledge 词条正文，按 Markdown 为主实现（GAP D5）。

## 2. 任务自动编排算法

- [ ] “建议顺序”的优先级你更看重哪个？
  - 截止时间
  - 依赖关系
  - 预估时长
  - 优先级
  - 时间块精力属性
  - 组合排序
  - ✅ 定稿决定：改为**加权综合评分**——总分 =（紧急度 × 0.4）+（目标匹配度 × 0.3）+（状态适配度 × 0.2）−（同类疲劳惩罚 × 0.1）（定稿 1.1.3；分量归一与缺省常量见 GAP §4.1）；重排**仅**由用户点击“更新与排序”触发（定稿 1.1.3 / GAP D8），旧“任务建议清单”降级为创建时/显式点按的辅助建议（D8）。
- [ ] 是否允许任务自动占用时间块，还是只给建议、用户手动确认？
  - ✅ 定稿决定：**不自动占用、不自动重排**——排序结果只在点击“更新与排序”后呈现（D8）；事件期望/截止时刻与日程块冲突时仅弹窗警告，并提供“移至该日程块之前/之后”一键调整（定稿 1.2.3；GAP §2.2 表）。

## 3. 挖空方式

- [ ] 知识点模板通常由作者手动配置，还是希望软件根据正文“智能挖空”？
  - ✅ 定稿决定：两者并入**自由挖空**机制（定稿 1.3.2）——每次抽卡按概率决定是否创造“历史未出现”的新空位（newClozeProbability = 0.5，GAP §4.2），无新空位则打内部标记、仅从历史方式抽取；作者预设卡（CardTemplates）保留为 legacy，旧 `.kpak` 模板导入后照常生成 preset 卡（GAP §3 / §7 兼容）。
- [ ] 如果智能挖空，你希望优先挖“关键词/术语/数字/人名”中的哪些？
  - ✅ 定稿决定：定稿**未限定**挖空目标词类（无关键词/术语/数字/人名的优先规则）；首批槽位由现有 ClozeGenerator 从既有正文自动推导（GAP §7 兼容节：沿用 ClozeGenerator 逻辑增强），此后“新空位”仅要求历史未出现（定稿 1.3.2）。

## 4. 知识包附件

- [ ] 是否需要支持图片/音频/PDF 等附件？这会影响包体积和导入复杂度。
  - ✅ 定稿决定：**需要，且纳入全量打包**——附件、主题与 SQLite 数据一起压缩为单个 `.tfpkg` 工作区文件（定稿 §3；GAP D4 / §2.6），zip 内含 `attachments/*`（GAP §5 格式要点）；`.kpak` 保留为班级分享子集（不含个人数据，D4）。

## 5. 复习统计

- [ ] 需要哪些统计：连续打卡、每日复习数、正确率、遗忘曲线、预计下次复习？
  - ✅ 定稿决定：调度与“预计下次复习”改由 **FSRS** 完全本地计算（定稿 1.3.2 间隔重复；GAP D9），ReviewLogs / 卡状态扩展 stability、difficulty、due 等 FSRS 字段（GAP §3 数据层表）；既有“复习统计”作为保留能力适配 FSRS（GAP §7），定稿未另立新的报表型统计规格。

## 6. 提醒方式

- [ ] 任务提醒用系统通知就可以，还是需要日历视图/桌面小组件？
  - ✅ 定稿决定：任务提醒保留**系统本地通知**（现状 NotificationService，GAP §2.1 保留项 / §7 保留）；日历视图按定稿 1.2.2 在 Time 模块提供标准日/周/月视图（GAP §2.2 表，R5）；桌面小组件不在定稿范围。

## 7. 名称与视觉

- [ ] 产品最终名称？（暂定“知序 KnowFlow”）
  - ✅ 定稿决定：**Threadflow**（2026-09-07 定稿；GAP D1）——应用标题/文案/ARB 全部替换“知序/KnowFlow”，`pubspec.name` 改为 `threadflow`；工作目录沿用 `class-productivity/`（改名留到发布前）。
- [ ] 视觉风格偏好：简洁冷淡 / 活力彩色 / 护眼深色？
  - ✅ 定稿决定：不做固定单选，改为**高自定义外观系统**：主/辅主题色、背景色/透明度/背景图、UI 与正文字体分设、页面缩放 80%–150%、动画开关；内置官方深/浅默认主题，全部配置打包为可导入导出的 JSON 主题文件（定稿 §4；GAP D13）。
