# Furnace UI 简化审计（2026-11-03）

## 0. 2026-11-03 追加：题库页「AI 题单」

- 题库页 AppBar 增加带文字的「AI 题单」主操作：自动选 6 题（每科 2 题、排除历史用题），把题干图+答案图交给内置多模态模型，生成单文件 Markdown 题单（含无颜色形状思维树）。
- 用户不需要自己挑题、贴图、排版；入口只有一个，生成过程有进度与结果路径。

> 用户反馈：很多界面复杂、目的不明确；闪存卡设置「添加卡组」只是右上角小加号；各界面右上角按钮有时相同有时不同；手动管理闪存卡的界面用户用不上。本文件记录已改、待改与统一规则。

## 3. 统一交互规则（后续按此改）

1. AppBar 主操作：最多一个，必须带文字（如「新建卡组」「收题」），不用纯图标。
2. 次操作：全部收进「更多」菜单；菜单项带图标+文字，按频率排序。
3. 破坏性操作：删除/清空放菜单底部，红色文字，二次确认。
4. 页面目的：每个页面标题下方一句副标题（≤20 字）说明这页能做什么，不写实现术语。
5. 空态：说明 + 一个主按钮 + 最多 3 步指引。
6. 移动端：底部导航 ≤5 项；多出来的进「更多」。
7. 术语表：只使用用户能懂的词（卡组、闪存卡、题目、知识点），不出现工具名/算法名。
